🛡️ Intégrité
Détection de toute modification en transit
via codes d'authentification de message (MAC)
HMAC-SHA256 HMAC-SHA384 AEAD (GCM/Poly)

🪪 Authentification
Vérification de l'identité du serveur (et client en mTLS)
via certificats X.509 signés par une CA de confiance
X.509 v3 RSA / ECDSA PKI / CA Chain
mTLS : authentification mutuelle client ↔ serveur

DÉRIVATION MASTER SECRET
pre_master_secret ──PRF(SHA-256)──► master_secret (48B)
= PRF(PMS, "master secret", client_random ∥ server_random)

master_secret ──PRF "key expansion"──► key_material
→ client_write_key · server_write_key · client_write_IV · server_write_IV

0 (ou PSK)──► HKDF-Extract──► Early Secret
↓ HKDF-Expand("derived")
DHE ──► HKDF-Extract──► Handshake Secret

→ server_handshake_traffic_secret
↓ HKDF-Expand("derived")
0 ──► HKDF-Extract──► Master Secret
→ client_application_traffic_secret
→ server_application_traffic_secret

Cipher suites à éviter (TLS 1.2) :
✗ *_RC4_* — biais statistiques connus  |  ✗ *_NULL_* — aucun chiffrement
✗ *_EXPORT_* — FREAK attack  |  ✗ *_anon_* — pas d'authentification
⚠ *_RSA_* (KEX) — pas de PFS  |  ⚠ *_3DES_* — SWEET32 attack (64-bit blocs)

TLS 1.2 vs TLS 1.3 — TABLEAU COMPARATIF
Critère TLS 1.2 TLS 1.3 Verdict
Latence 2-RTT (4 demi-échanges avant données) 1-RTT + 0-RTT possible (session resumption) 1.3 ✓
Forward Secrecy Optionnel (RSA key exchange sans PFS possible) Obligatoire — ECDHE/DHE uniquement 1.3 ✓
Échange de clés RSA, DH, ECDH, ECDHE, DHE ECDHE + DHE seulement (PFS garanti) 1.3 ✓
Cipher Suites ~37 suites (dont beaucoup dangereuses) 5 suites seulement (toutes AEAD) 1.3 ✓
Handshake chiffré Non — Certificate visible en clair Oui dès ServerHello (Certificate, CertVerify) 1.3 ✓
Compression Oui → CRIME attack (2012) Supprimée 1.3 ✓
Renegotiation Possible → Triple Handshake attack Supprimée (KeyUpdate message à la place) 1.3 ✓
Session Resumption Session ID ou Session Tickets Pre-Shared Key (PSK) — plus sécurisé 1.3 ✓
Algorithmes supprimés RC4, 3DES, MD5, SHA-1, DSA, EXPORT Tout sauf AES-GCM, ChaCha20, SHA-256+ 1.3 ✓
Compatibilité Large (legacy systems) Middleboxes parfois problématiques (GREASE) Contexte
COMMANDES OPENSSL
# Test connexion TLS (verbose) $ openssl s_client -connect example.com:443 -tls1_3 # Voir le certificat et la chaîne $ openssl s_client -showcerts -connect example.com:443 -quiet # Analyser un certificat PEM $ openssl x509 -in cert.pem -text -noout # Vérifier validité / expiration $ openssl x509 -in cert.pem -dates -noout # Vérifier la chaîne de confiance $ openssl verify -CAfile ca-bundle.crt cert.pem # Générer clé privée RSA 4096 $ openssl genrsa -out key.pem 4096 # Générer clé EC (P-256, recommandée) $ openssl ecparam -name prime256v1 -genkey -out ec-key.pem # Créer une CSR $ openssl req -new -key key.pem -out csr.pem # Cipher suites supportées (nmap) $ nmap --script ssl-enum-ciphers -p 443 example.com # Test qualité TLS (en ligne) → https://www.ssllabs.com/ssltest/ → https://testssl.sh/ (script bash local)
