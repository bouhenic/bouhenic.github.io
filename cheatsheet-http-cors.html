Structure d'une requête HTTP

GET /api/users HTTP/1.1         ← ligne de requête
Host:          api.example.com   ← serveur ciblé
User-Agent:    Mozilla/5.0 …     ← client HTTP
Accept:        application/json   ← format souhaité
Content-Type:  application/json   ← format envoyé
Authorization: Bearer TOKEN       ← identité/droits
Origin:        https://site.com   ← sécurité CORS
                                   ← ligne vide CRLF
{"username":"alice","pwd":"…"}   ← body (POST/PUT)
Headers = QUI parle, QUOI faire, COMMENT répondre.
Body = données métier, uniquement en POST / PUT / PATCH.

Structure d'une réponse HTTP

HTTP/1.1 200 OK                  ← ligne de statut
Content-Type:  application/json   ← format du body
Content-Length: 256               ← taille (octets)
Cache-Control: no-cache           ← mise en cache
Set-Cookie:    sid=x; HttpOnly    ← cookie client
Access-Control-Allow-Origin: *    ← visa CORS
Access-Control-Allow-Methods: GET,POST
Access-Control-Allow-Headers: Authorization
                                   ← ligne vide CRLF
{"id":42,"name":"Alice"}          ← body JSON
Client : lit le code → analyse headers CORS → parse le JSON → met à jour l'UI.

Same-Origin Policy (SOP)

Le navigateur bloque toute requête vers une origine différente.
Même origine = protocole + domaine + port identiques.
URL cibleDepuis https://monsite.com
https://monsite.com/api ✓ Même origine
https://api.partenaire.com ✗ Domaine diff.
http://monsite.com ✗ Protocole diff.
https://monsite.com:8080 ✗ Port diff.

CORS — La négociation en 4 étapes

① Chargement — le navigateur charge HTML/JS depuis monsite.com (même origine → OK).
② Requête cross-origin — le JS appelle api.partenaire.com, le navigateur joint l'en-tête Origin:
③ Autorisation serveur B — il examine l'Origin et renvoie le visa : Access-Control-Allow-Origin:
④ Contrôle navigateur — Origin ↔ visa correspondent → données transmises au JS. Sinon : erreur CORS.

Config CORS Express

// Dev — tout autoriser
const cors = require('cors');
app.use(cors());
⚠ jamais en prod

// Prod — origine précise
app.use(cors({
  origin: 'https://frontend.com',
  methods: ['GET','POST'],
  allowedHeaders: [
    'Authorization',
    'Content-Type'
  ],
  credentials: true
}));

// Route spécifique :
app.get('/pub',cors(),(req,res)=>…)
