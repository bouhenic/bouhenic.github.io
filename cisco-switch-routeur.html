② Mots de passe — Sécurisation accès

SEC Passwords
! Mot de passe enable (mode priv.)
enable secret Cisco1234!    ← MD5

! Mot de passe console (accès physique)
line console 0
  password Console1!
  login
  exec-timeout 5 0        ← 5 min

! Mot de passe aux (modem)
line aux 0
  password Aux1234!
  login

! Chiffrement de TOUS les passwords
service password-encryption   ← type 7

! Longueur min mot de passe
security passwords min-length 8
⚠ Toujours préférer enable secret (MD5) à enable password (clair).

③ Interface de gestion Switch (SVI VLAN 1)

MGMT IP de gestion
! SVI (Switch Virtual Interface) VLAN 1
interface vlan 1
  ip address 192.168.1.10 255.255.255.0
  no shutdown

! Passerelle par défaut du switch
ip default-gateway 192.168.1.1

! Vérification
show interface vlan 1
show ip interface brief
Sur un switch L2, la SVI sert uniquement à la gestion (SSH, Telnet).
Sur switch L3 : une SVI par VLAN pour le routage.

④ Accès distant — Telnet (non chiffré)

TELNET Port 23 — Non sécurisé
! Configuration des lignes VTY (0 à 15)
line vty 0 4                 ← 5 sessions simultanées
  password Telnet1234!
  login                       ← auth par password
  transport input telnet      ← ou : all
  exec-timeout 10 0

! Avec base de données locale (recommandé)
username admin privilege 15 secret Admin123!
line vty 0 4
  login local                 ← auth base locale
  transport input telnet

! Test depuis un PC
telnet 192.168.1.10
⚠ Telnet transmet tout en clair ! À n'utiliser qu'en labo isolé. En production → SSH.

⑤ Accès distant — SSH v2 (chiffré ✔)

SSH v2 Port 22 — Chiffré & Authentifié
! 1. Nom de domaine obligatoire (clé RSA)
ip domain-name newton.local

! 2. Créer un compte local avec privilege 15
username admin privilege 15 secret Admin123!

! 3. Générer la paire de clés RSA (≥ 1024 bits)
crypto key generate rsa
  → How many bits in the modulus? 2048

! 4. Forcer SSH version 2
ip ssh version 2
ip ssh time-out 60
ip ssh authentication-retries 3

! 5. Lignes VTY — SSH uniquement
line vty 0 15
  login local
  transport input ssh        ← bloquer Telnet

! Vérification & test
show ip ssh
show ssh
! Depuis PC Linux/Mac :
ssh -l admin 192.168.1.10

⑥ Adressage IP — Interfaces routeur

ROUTEUR Interfaces physiques & Loopback

interface GigabitEthernet 0/0
  description Connexion LAN VLAN-10
  ip address 192.168.10.1 255.255.255.0

interface Serial 0/0/0
  description Lien WAN FAI

⑦ VLANs — Switch L2 (création & ports access)

VLANs Segmentation logique
! Création des VLANs
vlan 10
  name VLAN-DIRECTION
vlan 20
  name VLAN-PROF
vlan 30
  name VLAN-ELEVES
vlan 99
  name VLAN-MGMT

! Port ACCESS (PC, serveur → 1 seul VLAN)
interface FastEthernet 0/1
  switchport mode access
  switchport access vlan 10
  spanning-tree portfast    ← terminaux seulmt

! Désactiver ports inutilisés
interface range Fa0/10 - 24
  switchport mode access
  switchport access vlan 999  ← VLAN poubelle
  shutdown

! Vérifications
show vlan brief              ← liste VLANs + ports
show interfaces Fa0/1 switchport

⑧ Trunk 802.1Q — Liaison entre switches / routeur

TRUNK 802.1Q — Transport multi-VLANs
! Port TRUNK (switch ↔ switch, switch ↔ routeur)
interface GigabitEthernet 0/1
  description Trunk vers SW-DISTRIB
  switchport trunk encapsulation dot1q  ← si requis
  switchport mode trunk
  switchport trunk native vlan 99      ← VLAN natif ≠ 1
  switchport trunk allowed vlan 10,20,30,99

! Ajouter / retirer un VLAN du trunk
switchport trunk allowed vlan add 40
switchport trunk allowed vlan remove 30

! Négociation DTP (à désactiver en prod)
switchport nonegotiate              ← désactive DTP

! Vérifications
show interfaces trunk               ← tous les trunks
show interfaces Gi0/1 trunk
VLAN natif : trafic non taggué — doit être identique des deux côtés du trunk.

⑨ Routage statique — Table de routage manuelle

STATIC Routes statiques & par défaut

⑩ Inter-VLAN — Router-on-a-Stick (sous-interfaces)

RoaS 1 lien physique + N sous-interfaces
!── CÔTÉ SWITCH ─────────────────────────────
! Port vers le routeur = TRUNK
interface Gi0/24          ← port uplink routeur
  switchport trunk encapsulation dot1q
  switchport mode trunk
  switchport trunk native vlan 99

!── CÔTÉ ROUTEUR ────────────────────────────
! Interface physique allumée SANS IP
interface GigabitEthernet 0/0
  no shutdown

! Sous-interface VLAN 10
interface GigabitEthernet 0/0.10
  encapsulation dot1Q 10      ← tag VLAN
  ip address 192.168.10.1 255.255.255.0

! Sous-interface VLAN 20
interface GigabitEthernet 0/0.20
  encapsulation dot1Q 20
  ip address 192.168.20.1 255.255.255.0

! Sous-interface VLAN natif (sans tag)
interface GigabitEthernet 0/0.99
  encapsulation dot1Q 99 native
  ip address 192.168.99.1 255.255.255.0

! Vérification
show ip interface brief
ping 192.168.20.10    ← depuis un PC VLAN 10
Chaque PC configure sa passerelle par défaut = IP de la sous-interface de son VLAN.
Limite : tout le trafic inter-VLAN passe par le lien trunk physique (goulet d'étranglement).

⑪ Serveur DHCP — Sur le routeur Cisco

DHCP Attribution IP automatique
! Exclure les IP réservées (routeur, serveurs)
ip dhcp excluded-address 192.168.10.1 192.168.10.10
ip dhcp excluded-address 192.168.20.1 192.168.20.10

! Pool VLAN 10
ip dhcp pool POOL-VLAN10
  network 192.168.10.0 255.255.255.0
  default-router 192.168.10.1    ← passerelle
  dns-server 8.8.8.8 1.1.1.1
  lease 7                        ← bail 7 jours
  domain-name newton.local

! Pool VLAN 20
ip dhcp pool POOL-VLAN20
  network 192.168.20.0 255.255.255.0
  default-router 192.168.20.1
  dns-server 8.8.8.8
  lease 1

! Si DHCP distant (relay agent)
interface Gi0/0.10
  ip helper-address 192.168.99.100  ← IP serveur DHCP

! Vérifications
show ip dhcp pool               ← config des pools
show ip dhcp binding            ← baux actifs
show ip dhcp conflict           ← conflits IP
clear ip dhcp binding *         ← vider les baux

⑫ Switch L3 — Routage inter-VLAN natif (Catalyst 3560/3750/3850…)

SWITCH L3 SVIs + ip routing — Solution recommandée en production
Activation du routage
! Activer le routage IP (obligatoire)
ip routing              ← commande clé !

! SVI par VLAN (= passerelle des PCs)
interface vlan 10
  description Gateway VLAN-DIRECTION
  ip address 192.168.10.1 255.255.255.0
  no shutdown

interface vlan 20
  description Gateway VLAN-PROF
  ip address 192.168.20.1 255.255.255.0
  no shutdown

interface vlan 30
  description Gateway VLAN-ELEVES
  ip address 192.168.30.1 255.255.255.0
  no shutdown
Port routé vers routeur WAN
! Transformer un port switch en port routé
interface GigabitEthernet 1/0/1
  description Uplink vers R1 (port routé)
  no switchport             ← mode routé !
  ip address 10.0.0.2 255.255.255.252
  no shutdown

! Route par défaut vers le routeur WAN
ip route 0.0.0.0 0.0.0.0 10.0.0.1

! OSPF sur le switch L3
router ospf 1
  router-id 3.3.3.3
  network 192.168.10.0 0.0.0.255 area 0
  network 192.168.20.0 0.0.0.255 area 0
  passive-interface vlan 10
  passive-interface vlan 20
