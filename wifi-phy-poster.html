Métriques diagnostiques de la couche PHY

MétriqueUnitéDescriptionSeuil critique
RSSI dBm Puissance du signal reçu (Received Signal Strength Indicator) ≥ −70 dBm
SNR dB Rapport signal/bruit — espace libre au-dessus du plancher de bruit ≥ 25 dB
Noise Floor dBm Plancher de bruit ambiant (Bluetooth, micro-ondes, autres réseaux) ≤ −95 dBm
EVM dB Error Vector Magnitude — déviation des symboles sur la constellation ≤ −25 dB
BER ratio Bit Error Rate — proportion de bits corrompus en réception ≤ 1×10⁻⁶
BW canal MHz Largeur spectrale du canal (20 / 40 / 80 / 160 / 320 MHz) 320 MHz (Wi-Fi 7)

Le SNR dicte les règles du jeu

SNR (dB)  =  RSSI (dBm)  −  Noise Floor (dBm)
Exemple concret
RSSI        = −85 dBm   ← signal reçu
Noise Floor = −100 dBm  ← bruit ambiant
              ──────────
SNR         = +15 dB    ← marge exploitable
Barème SNR → usage
> 35 dB 1024-QAM (MCS 10-11), Wi-Fi 6/7 peak
25–35 dB Vidéo HD — 256-QAM (MCS 8-9)
15–25 dB Navigation web — 64-QAM → 16-QAM
< 15 dB Survie uniquement — BPSK / QPSK
✓ Le système réagit à l'espace libre au-dessus du bruit (SNR), pas uniquement à la puissance absolue du signal (RSSI).

Le codage FEC — Réparer mathématiquement les dégâts causés par le bruit

Principe du Forward Error Correction
L'émetteur ajoute des bits de redondance mathématique aux données utiles. Le récepteur peut reconstruire les données corrompues sans retransmission, en utilisant ces bits comme stencil de reconstruction.
MCS 0 — Codage 1/2
50% données
50% redondance
Bouclier lourd — survie aux longues distances et fortes interférences
MCS 7 — Codage 5/6
83% données
17% redondance
Très rapide — incapable de survivre à une forte interférence
Diagnostic : Un codage FEC élevé protège les données mais réduit le débit utile. Le système choisit dynamiquement le ratio optimal selon la qualité du canal (SNR réel).

L'intervalle de garde — Prévenir les collisions temporelles (multipath)

L'intervalle de garde est le temps de pause obligatoire entre chaque transmission de symbole OFDM. Il absorbe les échos provoqués par les réflexions sur les obstacles (fenêtres, murs, sol).
Long GI — 800 ns Sûr
🚗 ⟵800ns⟶ 🚗 ⟵800ns⟶ 🚗
Robuste contre les échos et le trajet multiple. Idéal pour les environnements complexes.
Court GI — 400 ns Risqué
🚗400 🚗400 🚗400 🚗
Débit accéléré (+11%) mais très vulnérable aux collisions si signal rebondit sur un mur.
Réduire le GI accélère le débit physique, mais exige un environnement RF 'propre' sans obstacles réfléchissants.

⚠ La Limite Physique
Chaque génération ajoute des 'vitesses' supérieures à la boîte MCS. Atteindre 4096-QAM requiert un SNR colossal (>43 dB). Sans signal parfait, un client Wi-Fi 7 rétrogradera automatiquement aux mêmes modulations qu'un client Wi-Fi 4.
