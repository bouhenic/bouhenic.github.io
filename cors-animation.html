01
📥 Le Chargement
Le navigateur charge la page HTML + JS depuis le Serveur A (monsite.com). Même origine — aucune restriction.
02
🛂 La Tentative d'Accès
Le JS appelle l'API du Site B. Le navigateur attache automatiquement le "passeport" :
Origin: https://monsite.com
03
🟩 L'Autorisation
Le Serveur B examine l'Origin et répond avec le "visa" :
Access-Control-Allow-Origin: https://monsite.com
04
🔍 Le Contrôle de Sécurité
Le navigateur compare l'origine avec le visa. Si ça correspond → données transmises au JS.
