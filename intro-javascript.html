Slide 01 — Contexte

Histoire de JavaScript

De Mocha à la conquête du web — en seulement 10 jours.

1995 — Netscape
Brendan Eich crée le langage en 10 jours
Objectif : rendre les pages web dynamiques dans le navigateur Netscape Navigator.
1995 — Mocha → LiveScript
Deux renommages successifs
D'abord appelé Mocha, puis LiveScript avant la version finale.
1995 — JavaScript
Le nom définitif, inspiré de Java
Choix marketing pour profiter de la popularité de Java (Sun Microsystems) — mais les deux langages sont très différents.
2009 — Node.js
JavaScript sort du navigateur
Ryan Dahl crée Node.js : JS peut maintenant s'exécuter côté serveur.
Aujourd'hui
Langage n°1 du web
Utilisé côté client (navigateur) ET côté serveur (Node.js, Deno, Bun).
💡 Java ≠ JavaScript — La ressemblance des noms est purement commerciale. Java est un langage compilé orienté objet ; JavaScript est un langage de script interprété, dynamiquement typé.

Slide 02 — Usages

Pourquoi utiliser JavaScript ?

Un seul langage pour tout faire — du bouton au serveur.

🎨

Interactivité UI

Modifier les couleurs, styles, positions des éléments HTML en temps réel selon les actions de l'utilisateur.

📝

Validation de formulaires

Vérifier les données côté client avant soumission au serveur — feedback immédiat sans rechargement de page.

🎮

Jeux & animations

Canvas 2D/3D, WebGL, animations CSS contrôlées dynamiquement. JS alimente des jeux entiers dans le navigateur.

🖥️

Serveur (Node.js)

Avec Node.js, JavaScript peut créer des serveurs web, des APIs REST, des applications full-stack.

📱

Applications mobiles

React Native, Ionic : créer des apps mobiles iOS/Android avec du JavaScript.

🤖

IoT & embarqué

Microcontrôleurs (Espruino, Johnny-Five), scripts d'automatisation, outils CLI via Node.js.

✅ JavaScript est le seul langage nativement compris par tous les navigateurs. C'est le langage incontournable du développement web, côté client comme côté serveur.

⬅ Côté Client (traditionnel)

Le code JS est envoyé au navigateur avec la page HTML. Le navigateur l'interprète grâce à son moteur JS intégré. Le code est visible par l'utilisateur (F12).

➡ Côté Serveur (Node.js)

Depuis 2009, JS s'exécute aussi sur le serveur. Le code reste caché côté serveur. Même syntaxe, mais accès aux fichiers, bases de données, réseau…

⚠️ Le JavaScript côté client est visible par tout le monde via les outils de développement (F12). Ne jamais mettre de secrets (mots de passe, clés API) dans du JS côté client !

Slide 04 — Moteurs

Les moteurs JavaScript

Un moteur JS convertit votre code en instructions machine.

⚙️ Un moteur JavaScript est un interpréteur/compilateur JIT qui parse votre code JS, le compile en bytecode ou en code machine, et l'exécute. Chaque navigateur possède le sien.
V8
Google V8 — Chrome, Chromium, Node.js
Le plus performant et le plus répandu. Utilisé dans Chrome, Edge (Chromium), et Node.js. Open-source.
SM
SpiderMonkey — Firefox
Le premier moteur JS de l'histoire, créé par Brendan Eich pour Netscape. Maintenu aujourd'hui par Mozilla.
JSC
JavaScriptCore (Nitro) — Safari
Développé par Apple pour Safari et WebKit. Aussi utilisé dans React Native sur iOS.
CK
Chakra → V8 — Microsoft Edge (historique)
Développé pour IE/Edge. Depuis le passage d'Edge à Chromium, Microsoft utilise désormais V8.
pipeline JIT — V8
// Pipeline simplifié du moteur V8
Code JS → Parser (AST) → Ignition (bytecode) → TurboFan (JIT)
         // AST = Abstract Syntax Tree
         // JIT = Just-In-Time compilation → code natif

Slide 05 — Outils

La console du navigateur

F12 → Console — votre meilleur outil de développement et débogage.

▶️

Exécution directe

Taper du code JS directement dans la console pour l'exécuter instantanément. Idéal pour tester des expressions.

🐛

Débogage

Les erreurs JS apparaissent en rouge avec le fichier source et le numéro de ligne. Point d'entrée essentiel pour diagnostiquer les bugs.

📋

Journalisation

Utiliser console.log() pour afficher des valeurs, suivre l'exécution, et inspecter des objets pendant le développement.

🔬

Inspection d'objets

Explorer la structure des objets JS, le DOM, les variables globales en temps réel sans modifier le code source.

LES MÉTHODES ESSENTIELLES

javascript — console API
// Affichage standard
console.log("Bonjour BTS CIEL");       // → texte en blanc
console.log(42, true, [1,2,3]);    // → plusieurs valeurs

// Niveaux de gravité
console.info("Information");         // → bleu ℹ️
console.warn("Attention !");         // → jaune ⚠️
console.error("Erreur critique");    // → rouge ❌

// Mesure de performance
console.time("mesure");
// ... code à mesurer ...
console.timeEnd("mesure");           // → mesure: 12.3ms

// Inspection d'objets
console.dir(document.body);          // → arbre DOM interactif
console.table([{nom:"Alice",age:17}]); // → tableau formaté
🔑 La console est l'interface entre le développeur et le moteur JavaScript. Elle donne accès direct à l'état de la page, aux variables globales (window), au DOM, et à tous les objets JavaScript chargés.
